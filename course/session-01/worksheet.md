## 00:35 – 01:20 · 계정 가입 (45분)

AI가 화면 순서를 한 단계씩 불러 준다. **입력과 인증은 내가 한다.** 비밀번호·인증 코드는 AI에게 불러 주지 않는다.

- **GitHub 먼저.** Supabase · Vercel은 "GitHub로 계속"으로 가입한다.
- **카드 입력 화면이 나오면 멈추고 한 화면 뒤로** 간다. 전부 무료 요금제로 된다.
- 한 서비스에서 5분 넘게 막히면 `미가입`으로 적고 다음 서비스로 간다. 막힌 화면의 글자는 「가입 화면에서 막혔을 때」 문장으로 AI에게 그대로 준다.

### 계정 가입 체크표

| 서비스 | 오늘 만드는 것 | 적어 둘 이름(비밀번호 말고) | 됐나 |
|---|---|---|---|
| GitHub | 계정 + **비공개(Private) 빈 저장소** — 이름은 프로젝트 폴더와 같게, README 칸은 비워 둔다 | 아이디: ________ 저장소: ________ | ☐ |
| Supabase | GitHub로 로그인 + 조직(Free). **프로젝트 만들기 화면에서 멈춘다** | 조직: ________ | ☐ |
| Vercel | GitHub로 로그인 · Hobby. **가져오기(Import)는 하지 않는다** | 팀: ________ | ☐ |
| 디스코드(선택) | 계정 · 서버 · 채널 — 시간이 남을 때만 | 서버: ________ | ☐ |
| 텔레그램(선택) | 폰 앱 가입 — 시간이 남을 때만 | @________ | ☐ |

## 01:30 – 02:00 · 1차 인터뷰 「회사·업종」 (30분)

### 1) 시작 — P4

**새 대화를 열고** `P4` 를 넣는다. 첫 질문은 회사(사업자) 이름과 대표님 호칭이다. **지금부터는 답만 하면 된다.**

### 2) 답할 때 지킬 것

- 회사에서 **평소 쓰는 말 그대로** 답한다. 멋진 말로 바꾸지 않는다.
- 모르겠으면 "모르겠다"고 한다. AI가 예를 들어 준다.
- 고객 이름·금액·연락처·주소는 말하지 않는다. "고객 A", "얼마"로 충분하다.
- 질문이 한꺼번에 두세 개 오면 "하나씩만 물어봐 주세요"라고 다시 말한다.
- 지치면 "잠깐 쉬었다 할게요", 그만하려면 "여기까지 하고 다음에"라고 한다. 남은 질문은 2회차 첫머리에 다시 묻는다.
