# 2회차 — 오늘 반드시 끝내는 것

저장·배포와 사람 · 3시간

오늘의 완료선은 하나다. **직원 계정으로 입력하고 다시 접속해도 저장된 내용이 보이는 앱 — 실제 주소에서.**

1회차 초안은 브라우저를 닫으면 내용이 사라진다. 오늘은 그것을 **남는 것**으로 바꾸고, 주소를 만들고, 누가 무엇을 보는지를 정한다.

---

## 수업 전 확인

- 번들 재설치 공지를 받았으면 1회차 P2 설치 문장을 같은 명령으로 한 번 더 실행한다 — 이미 고친 파일은 지워지지 않고 새 버전이 같은 자리에 `.new`로 저장되니, 비교해서 옮길 것이 있으면 옮기고 `.new`는 지운다.

---

## 오늘의 완료선

| 항목 | 완료로 보는 기준 |
|---|---|
| **저장** | 입력하고 새로고침해도 그대로 있다 |
| **주소** | `...vercel.app` 로 열린다 |
| **사람** | 직원 계정으로 로그인해 한 건을 입력할 수 있다 |
| **잠금** | 로그아웃 상태로 목록 주소를 직접 열면 아무것도 안 보인다 |

네 줄 중 **저장**이 최소선이다. 배포까지 못 가도 저장이 되면 오늘은 넘어간 것이고, 주소는 과제로 이어서 만든다.

## 손에 남는 것

### 1. 개선 1~2건

회차 사이에 적어 온 세 줄(`company/log.md`)에서 시작한다. AI가 찾은 문제가 아니라 **대표와 직원이 실제로 막힌 자리**를 고친다.

- `company/improve-plan.md` — 전·후·확인 방법·데이터 영향

### 2. 백업 — 저장보다 먼저

- `company/backup.md` — 내려받는 방법 · 두는 곳 · **되찾는 순서**
- 파일을 한 번 내려받아 **열어 봤다**. 열어 보지 않은 백업은 백업이 아니다.

### 3. 저장할 자리

- `supabase/migrations/0001_init.sql` — 표 하나. 칸 이름은 영문, 우리 회사 말은 주석으로.
- 잠금(행 수준 보안)을 **표를 만들 때 같이** 걸었다. "나중에 켜자"로 미룬 잠금은 대개 안 켜진다.
- `company/data.md` — 무엇을 어디에 담았는지

### 4. 인터넷 주소

- GitHub 비공개 저장소 → Vercel 배포
- `.env.local` 이 저장소에 올라가지 않았다
- Vercel 환경 변수가 들어가 있다(값은 화면에 찍지 않는다)

### 5. 사람과 권한

- `company/people.md` — 역할 2종(대표·직원)과 **절대 보이면 안 되는 것** 목록
- 역할마다 첫 화면이 정해져 있다
- 역할 칸이 빈 계정으로는 아무것도 안 보인다

### 6. 오늘 것 검수·보고서

- 감독 판정 → 검증 실측 → `reports/` 에 보고서 한 장
- `.owner/last-check.json` 이 오늘 날짜로 갱신돼 있다

## 확인 기준 — 내가 직접 눌러 본다

AI의 "완료했습니다"는 확인이 아니다. 아래는 전부 **대표가 손으로** 확인하는 것이다.

### 저장

- [ ] 한 건을 입력하고 **새로고침**해도 그대로 있다
- [ ] 브라우저를 껐다 켜도 남아 있다
- [ ] 목록 조회에 **정렬과 개수 제한**이 들어가 있다

### 주소

- [ ] 배포 주소가 열린다
- [ ] 폰에서도 열린다
- [ ] 저장소에 `.env.local` 이 없다

### 사람·권한

- [ ] 직원 계정으로 로그인해 한 건을 넣었다
- [ ] 직원 계정에서 **대표만 봐야 할 것**이 안 보인다
- [ ] **로그아웃 상태**로 목록 주소를 직접 열면 아무것도 안 보인다
- [ ] 역할 칸이 빈 계정으로는 아무것도 안 보인다
- [ ] 목록뿐 아니라 **상세·검색·사진·파일**까지 확인했다

### 백업

- [ ] 내려받은 파일을 **열어 봤다**(빈 파일이 아니고 한글이 안 깨진다)
- [ ] 회사 드라이브에 `<날짜>_<이름>` 으로 뒀다. 바탕화면은 백업이 아니다

### 기록

- [ ] `reports/` 에 오늘 보고서가 있다
- [ ] `.owner/state.md` 의 현재 기능·미해결 문제가 오늘 것으로 고쳐졌다
- [ ] `git log` 에 오늘 커밋이 있다

## 오늘 알아 두는 생각 세 가지

1. **화면에서 숨기는 것과 데이터가 막힌 것은 다르다.** 메뉴를 감춰도 주소를 직접 치면 열린다. 막는 자리는 데이터를 가져오는 쪽이다.
2. **빈칸은 "아니오"가 아니다.** "이 역할이 아니면 거부"로 쓰면 역할이 비어 있는 계정이 검사를 그냥 통과한다.
3. **제한 없는 목록은 조용히 잘린다.** 오류도 안 나고 최근 것이 사라진다. 정렬과 개수 제한을 같이 건다.
