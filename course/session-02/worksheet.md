칸을 채우면서 따라온다. 5분 넘게 막히면 적어 두고 다음으로 간다.

AI에게 넣는 문장은 `prompts.md` 에 번호로 있다. 여기서는 `P1` 처럼 번호로만 부른다.

**오늘의 완료선**: 직원 계정으로 입력하고 다시 접속해도 내용이 남아 있는 앱(실제 주소).

## 00:10 – 00:45 · 써 보고 온 것 고치기 (35분)

### 1) 기록부터 읽힌다 — P1

`P1` 을 넣는다. AI가 자기 눈에 띄는 것부터 고치지 않게 **기록을 먼저 읽게** 하는 문장이다.

### 2) 오늘 고칠 것 한 건 정하기 — P2

> 고칠 것: ______________________________
>
> 확인 방법(무엇을 눌러 보면 됐는지 아는가): ______________________________

확인 방법이 없는 개선은 끝난 줄 알고 넘어간다.

### 3) 적용 — P3

한 건만 고친다. 두 개를 같이 고치면 문제가 생겼을 때 어느 쪽인지 모른다.

### 4) 내가 직접 확인 — P4

> 됐나: ☐ 됐다  ☐ 안 됐다 → 안 됐으면 원인 찾기 전에 되돌린다

### AI가 고치는 동안 — 인디언즈 이야기 4: 할 일은 사람이 적지 않는다, 일정이 만든다

> 우리 회사에서 '이 일이 시작되면 반드시 따라오는 일' 한 쌍: ______________________________

## 01:30 – 01:55 · 진짜 데이터로 갈아타기 (25분)

### 1) 한 화면씩 — P7

목록부터. 한 화면이 끝날 때마다 멈추고 내가 확인한다.

- [ ] 목록이 데이터베이스에서 온다
- [ ] 입력하고 **새로고침**해도 남아 있다
- [ ] 이메일·비밀번호 로그인 화면이 생겼다
- [ ] 목록 조회에 **정렬과 개수 제한**이 들어갔다

> 안 되는 화면: ______________________________

질문은 한 번에 하나씩. **"절대 보이면 안 되는 것"** 을 물을 때 "없다"고 넘기지 않는다.

> 2: ______________________________
>
> 3: ______________________________

### 2) 앱에 반영 — P10

P10 아래쪽에 AI에게 주는 규칙 일곱 줄이 붙어 있다. **뜻을 몰라도 지우지 말고 그대로** 넣는다.

- [ ] 로그인이 붙었다(아무나 가입되는 화면은 만들지 않는다)
- [ ] 대표·직원 두 역할로 나뉘고, 역할마다 첫 화면이 정해졌다
- [ ] `company/people.md` 가 생겼다

### AI가 권한을 반영하는 동안 — 인디언즈 이야기 6: 안 보이게 하는 것도 기능이다

> 우리 회사에서 '이건 저 사람에게는 안 보였으면' 하는 것: ______________________________

## 02:45 – 03:00 · 권한 확인과 마무리 (15분)

### 1) 가장 권한 낮은 자리에서 확인 — P11

관리자 화면에서 규칙만 보는 것은 확인이 아니다.

- [ ] 직원 계정으로 로그인해 봤다
- [ ] **로그아웃 상태**로 목록 주소를 직접 열어 봤다 → 아무것도 안 보인다
- [ ] 역할 칸이 빈 계정으로도 열어 봤다 → 아무것도 안 보인다
- [ ] 목록뿐 아니라 상세·검색·사진/파일까지 봤다

> 보이면 안 되는데 보인 것: ______________________________

### 2) 오늘 것 검수·보고 — P12

오늘은 저장 구조와 권한이 둘 다 바뀌었다. 되돌리기 어려운 쪽이라 **배포 전에 한 번 보고 간다.**

- [ ] 감독 판정을 받았다(반려면 고치고 다시 받았다)
- [ ] 보고서가 `reports/` 에 생겼다

### 3) 저장하기

```
git add -A
git commit -m "2회차"
```

### 4) 과제 안내

`homework.md` — 직원이 **자기 기기로** 접속해 실제 건 3건. 주소가 생겼다는 것은 주소를 아는 사람은 누구나 열어 본다는 뜻이기도 하다. 잠금 확인도 같이 한다.
