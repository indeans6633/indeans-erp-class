# 3회차 앞선 트랙 — 먼저 끝났다면

기본 트랙(창구 둘 + 운영 보고 예약 + 첫 수신)이 끝났고 시간이 남는 분용이다. 같은 시간표로 움직이되 **목표만 다르다.**

먼저 아래 두 가지가 **이미 되어 있어야** 이 카드로 간다. 하나라도 안 되면 그것부터 한다.

- 시험 발송이 아니라 **예약된 보고가 실제로 도착했다**
- `company/digest.md` 에 무엇을·언제·누구에게가 적혀 있다

아래에서 **하나만** 고른다. 오늘 끝나는 크기다.

---

## 앞 슬롯 (하나 고른다)

### A1. 받는 사람별로 나누기

**목표**: 대표가 받는 보고와 직원이 받는 보고를 다르게 만든다. 같은 글을 모두에게 보내면 양쪽 다 자기 것이 아니라고 느낀다.

```
지금 보고를 대표용과 직원용으로 나눠 줘.
직원용은 그 사람이 할 일만 담고, 회사 전체 숫자는 넣지 마.
누가 무엇을 받는지 표로 먼저 보여 주고, 내 확인을 받은 뒤에 고쳐 줘.
```

**확인**: 직원 계정으로 받는 보고에 대표만 봐야 할 것(전체 매출·다른 사람 건)이 섞이지 않았는가. 화면에서 막은 것과 보고에서 막은 것은 **별개**다.

### A2. 놓친 것 한 종류

**목표**: 사람이 잊어서 새는 지점 하나를 골라 보고에 한 줄로 넣는다.

```
{예정일이 지났는데 다음 단계로 안 넘어간 건}을 보고에 한 줄로 넣어 줘.
건수가 0이면 그 줄은 아예 빼고 보내 줘.
며칠 기준으로 '늦은 것'인지는 나한테 먼저 물어봐.
```

**왜 0이면 빼나** — 매일 "0건"이 오면 보고를 안 읽게 된다. **뭔가 있을 때만 보이는 줄**이 가장 잘 읽힌다.

---

## 뒤 슬롯 (하나 고른다)

### B1. 실패했을 때 다시 보내기

**목표**: 보내기가 실패해도 조용히 지나가지 않게 한다.

```
보내기가 실패하면 기록에 남기고, 잠시 뒤 한 번만 다시 보내게 해 줘.
두 번 다 실패하면 다음 보고에 "지난번 보고가 안 나갔습니다" 한 줄을 붙여 줘.
무한정 다시 보내지는 마.
```

**확인**: 주소를 일부러 틀리게 바꿔 한 번 실패시켜 본다. 기록에 남고, 다시 보내기가 한 번만 돌고, 다음 보고에 알림이 붙으면 통과다. **확인한 뒤 주소를 원래대로 되돌린다.**

### B2. 시각을 두 번으로

**목표**: 아침 보고(오늘 할 것)와 저녁 보고(오늘 끝난 것)를 나눈다.

```
보고를 아침과 저녁 두 번으로 나눠 줘.
아침은 오늘 할 것, 저녁은 오늘 끝난 것과 안 움직인 것으로.
두 보고가 같은 줄을 반복하지 않게 해 줘. 같은 날 중복으로 나가지 않는 것도 그대로 지켜 줘.
```

**주의** — 두 번으로 늘리면 읽는 양이 두 배가 된다. **한 번짜리가 잘 읽히고 있을 때만** 늘린다.

### B3. 보고 점검 스크립트

**목표**: 사람의 확인 대신 **매번 돌리는 검사**를 만든다. 같은 실수의 재발은 사람의 주의보다 기계 검사가 더 잘 막는다.

```
프로젝트에 읽기만 하는 점검 스크립트를 하나 만들어 줘. 아무것도 고치지 않는 스크립트야.
① 예약이 등록돼 있나 ② 최근 발송 기록에 실패가 있나
③ 같은 날 두 번 나간 적이 있나 ④ 보고 문장에 고객 실명·연락처·금액이 섞여 있나
를 검사해서 문제가 있으면 목록을 출력하고 실패로 끝내 줘. 깨끗하면 한 줄만 출력해.
비밀값은 화면에 출력하지 마.
```

**확인**: 일부러 예약을 잠시 끄고 돌려 본다. 잡아내면 성공이다. 잡아낸 뒤 되돌린다.

---

## 앞선 트랙에서도 지킬 것

- 작업 전 **되돌릴 지점(커밋)**을 만든다.
- 오늘 고른 것은 **하나**다. 두 개를 같이 시작하면 둘 다 확인 없이 끝난다.
- 자동으로 나가는 것을 바꿨으면 **한 번 받아 보는 것까지**가 끝이다. 문서에 적은 것으로 끝내지 않는다.
- 비밀값은 어떤 경우에도 화면·저장소에 내보내지 않는다.
- 바꾼 뒤에는 검수를 받는다.

```
indeans-erp-check 스킬을 읽고 방금 바꾼 것을 검수해 줘.
정해진 시각에 나가는 보고의 조건이 바뀌었으니 그 부분을 특히 봐 줘.
```

- 과제는 기본 트랙과 같다(`homework.md`). 앞서 있어도 **하루 받아 보고 한 줄 줄이는 것**은 건너뛰지 않는다.
