# 3회차 — 오늘 반드시 끝내는 것

채널과 운영 보고 · 3시간

오늘의 완료선은 하나다. **고른 채널에서 대표가 ERP 운영 보고를 실제로 받는 것.**

완료 기준이 분명하다 — **내 컴퓨터와 AI를 모두 꺼도 보고가 온다.** 내 컴퓨터가 켜져 있을 때만 오는 것은 보고 체계가 아니다.

---

## 오늘의 완료선

| 항목 | 완료로 보는 기준 |
|---|---|
| **창구** | 디스코드·텔레그램 두 곳에 시험 발송이 **폰에 도착**했다 |
| **보고 내용** | 무엇을·언제·누구에게가 `company/digest.md` 에 적혀 있다 |
| **서버 예약** | 예약이 실제로 등록된 것을 **조회해서** 봤다 |
| **첫 수신** | 수업 시간 안에 **한 번 받아 봤다** |

"연결했습니다"는 연결이 아니다. **폰에 글자가 뜬 것**이 연결이다.

---

## 손에 남는 것

### 1. 받을 창구 두 곳

- 디스코드 웹훅 · 텔레그램 봇 — **둘 다** 만든다. 한쪽이 막혔을 때 다른 쪽으로 갈 수 있다.
- `company/channel.md` — 받는 사람 · **여기로 보내지 않을 것**
- 비밀값(웹훅 주소·봇 토큰)은 `.env.local` 과 서버 쪽 비밀 저장에만. 화면에 출력하지 않고 저장소에 올리지 않는다.

### 2. 운영 보고 설계

- `company/digest.md` — 보고 항목표, 보내는 시각, 받는 사람(대표용 / 직원용 구분)
- 보고에 담는 것은 **앱을 열지 않아도 알아야 할 것**만. 열어 봐야 아는 것을 다 넣으면 아무도 안 본다.

### 3. 서버 예약

- 한국 시간으로 정해진 시각에 **서버가** 보낸다(내 컴퓨터·AI와 무관).
- 보낸 기록과 실패 기록이 남는다.
- 같은 날 두 번 보내지 않는다.

### 4. 오늘 것 검수·보고서

- 정해진 시각에 자동으로 나가는 것은 **내가 안 보는 사이에** 돈다. 조건이 틀리면 모르는 채로 계속 틀린다 — 그래서 검수 대상이다.
- 비밀값이 저장소나 화면에 노출되지 않았는지 같이 확인한다.

## 확인 기준 — 내가 직접 본다

### 창구

- [ ] 디스코드에 시험 글이 **내 폰에** 떴다
- [ ] 텔레그램에 시험 글이 **내 폰에** 떴다
- [ ] `company/channel.md` 에 "여기로 보내지 않을 것"이 적혀 있다(고객 실명·연락처·계좌·금액)
- [ ] 저장소에 웹훅 주소·봇 토큰이 없다

### 보고 내용

- [ ] 보고에 들어가는 줄이 **다섯 줄 안쪽**이다
- [ ] 각 줄이 **무엇을 어떻게 세었는지** 적혀 있어 앱 화면과 대조할 수 있다
- [ ] 대표가 받을 것과 직원이 받을 것이 구분돼 있다(직원용이 필요한 경우)

### 서버 예약

- [ ] 예약이 등록된 것을 **조회 결과로** 봤다("예약했습니다"라는 말이 아니라)
- [ ] 시각이 **한국 시간**으로 들어갔다
- [ ] 발송 기록·실패 기록이 남는 자리가 있다
- [ ] 같은 날 두 번 보내지 않게 막혀 있다

### 첫 수신

- [ ] 수업 중에 한 번 받아 봤다
- [ ] 받은 내용의 숫자가 앱 화면의 숫자와 같다
- [ ] 시각을 원래대로 되돌려 놨다

### 기록

- [ ] `reports/` 에 오늘 보고서가 있다
- [ ] `.owner/state.md` 가 오늘 것으로 갱신됐다
- [ ] `git log` 에 오늘 커밋이 있다

## 보고가 안 올 때 보는 순서

안 온 이유는 셋 중 하나다. **기록을 먼저 보면** 어디를 고칠지가 바로 나온다.

1. 예약이 **아예 안 돌았다** → 예약 등록·시간대를 본다
2. 돌았는데 **보내기에서 실패했다** → 실패 기록의 원문을 본다(주소·권한·형식)
3. 보냈는데 **내 폰에서 알림이 꺼져 있다** → 앱 알림 설정을 본다

## 오늘 하지 않는 것

- 보고 종류 늘리기 — 한 종류를 쓸 만하게 만드는 것이 먼저다
- 여러 채널로 동시 발송 — 둘 다 오면 둘 다 안 보게 된다
- **고객에게 가는 알림** — 아직 이르다. 내부에서 한 달은 돌려 본 뒤 대표 판단으로
- 두 번째 업무 흐름 — 4회차
