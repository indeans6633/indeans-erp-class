# 디자인 선택창 (2단계 · 2026-11-16 17:40 개정)

`index.html` 을 두 번 눌러 열면 됩니다(인터넷 필요 없음).

**1단계 — 테마 하나만.** 따뜻한 매장 · 큰 글씨 · 촘촘한 목록 · 우리 회사 색 네 장만 보여 줍니다. 각 카드 위에는 그 테마 기본 배치의 보드 축소판이 있고, 아래 「이런 업종」은 인터뷰 가지(B1~B8)에 맞춘 추천입니다. 하나를 고르고 「이 테마로 세부 설정」을 누릅니다.

인터뷰가 끝난 뒤에는 선택창을 `?branch=B3` 처럼 열면 그 업종에 맞는 테마가 먼저 골라져 있습니다(`?theme=shop` 도 됩니다). 다른 테마를 고르셔도 됩니다.

| 테마 | 느낌 | 잘 맞는 업종(인터뷰 가지) |
|---|---|---|
| 따뜻한 매장 (`shop`) | 밝은 크림 바탕, 사진이 크고 모서리가 둥글어요 | 가게·쇼핑몰(B2), 식당·카페·음식(B3), 학원·교습·강의(B6) |
| 큰 글씨 (`large`) | 글씨와 단추가 크고, 줄은 두껍고 모서리는 거의 없습니다 | 집 공사·수리·설치(B1), 예약·방문 서비스(B4) |
| 촘촘한 목록 (`list`) | 한 화면에 많이, 줄이 반듯하고 글씨는 작습니다 | 공장·제작·도매·유통(B5), 사무 서비스(B7) |
| 우리 회사 색 (`brand`) | 기본이 어두운 화면이고, 색 면이 넓게 들어갑니다 | 그 밖(B8), 로고 색을 살리고 싶을 때(모든 업종) |

**2단계 — 세부 설정.** 고른 테마로 밝기(밝게/어둡게), 메뉴 위치(왼쪽·위쪽·아래 탭), 본문 모양(카드·목록·보드), 우리 회사 색(해당 테마만), 미리 보기 화면(예시) · 휴대폰/PC 폭을 확인하고 「이걸로 하기」를 누릅니다. 테마마다 기본 배치가 있습니다(따뜻한 매장: 위쪽+카드, 큰 글씨: 아래+카드, 촘촘한 목록: 왼쪽+목록, 우리 회사 색: 위쪽+보드). 테마를 바꾸려면 「테마 다시 고르기」.

- 미리 보기 화면은 테마·업종 예시입니다. 실제 수업에서는 인터뷰에서 정한 화면 이름으로 바뀝니다.
- 색은 번들의 색 엔진(`app/color-engine.js`)이 계산합니다 — 글자 대비 4.5:1, 입력 칸 테두리 3:1을 어기지 않습니다. '우리 회사 색'에 아무 색을 넣어도 자동 보정됩니다.
- 글꼴: Pretendard · 고운바탕 서브셋(`fonts/`, OFL 라이선스 전문 동봉). 새 글꼴을 받아 쓰지 않습니다.
- '이걸로 하기' → AI에게 말할 문장(예: "디자인은 theme-shop-C45C26-light-top-cards 로 할게요.")이 나옵니다. 이 판은 저장 기능이 없는 미리 보기판입니다. 번들에 넣을 때 `design-pick.mjs` 가 이 두 단계를 그대로 열도록 맞춥니다(테마 고르기 → 세부 설정). 인터뷰 뒤 선택창은 `?branch=B3` 처럼 열어 추천 테마를 미리 고릅니다.
- 모든 회사·사람·연락처는 가짜입니다. 금액은 화면에 없습니다.
