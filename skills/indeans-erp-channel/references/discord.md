# 디스코드 창구 만들기 (대표가 직접 누르는 순서)

디스코드는 **보고가 쌓이는 쪽**입니다. 지난 보고를 거슬러 찾아볼 수 있고 파일도 올려 둘 수 있습니다.
여기서 만드는 것은 "웹후크(webhook)"입니다. 우리 앱이 **글을 써 넣을 수 있는 전용 주소** 하나라고 생각하면 됩니다.

---

## 1. 서버와 채널 만들기 (이미 쓰고 있으면 건너뜁니다)

1. 디스코드를 설치하고 로그인합니다(PC 프로그램·웹·폰 모두 같습니다. 아래는 PC 기준입니다).
2. 왼쪽 맨 아래 **+**(서버 추가하기) → **직접 만들기** → **나와 친구들을 위한 서버** → 서버 이름(예: 우리회사 운영) → 만들기.
3. 서버 안에서 채널 목록 옆 **+**(채널 만들기) → **텍스트** → 이름 `운영보고` → 만들기.

직원도 함께 받기로 했으면 채널을 **하나 더** 만듭니다(예: `직원알림`). 방을 나눠 두면 나중에 보낼 항목을 따로 정할 수 있습니다.

## 2. 웹후크 주소 받기

1. 채널 이름 위에 마우스를 올리고 **톱니(채널 편집)** 를 누릅니다.
2. 왼쪽에서 **연동**(Integrations) → **웹후크**(Webhooks) → **새 웹후크**.
3. 만들어진 웹후크를 눌러 이름을 알아보게 바꿉니다(예: 우리회사 보고). 프로필 사진은 그대로 둬도 됩니다.
4. **웹후크 URL 복사**를 누릅니다. 이 주소가 전부입니다.
5. 채널을 둘 만들었으면 두 번째 채널에서 2~4번을 한 번 더 합니다.

주소 모양: `https://discord.com/api/webhooks/<숫자>/<긴 글자>`

## 3. 주소를 어디에 두나

- 내 컴퓨터: 프로젝트 맨 위 `.env.local` 의 `DIGEST_DISCORD_URL=` 뒤에 붙입니다.
- 서버(정해진 시각 발송용): Supabase 의 설정 표 `app_secret`. `indeans-erp-digest` 의 `references/cron-sql.md` 2절.
- **그 밖에는 아무 데도 붙이지 않습니다.** 소스·회사 문서·캡처·화면 공유·메신저 전달 모두 안 됩니다.

주소를 아는 사람은 **그 채널에 글을 쓸 수 있습니다**(채널 내용을 읽지는 못합니다). 그래서 새면 장난 글이 올라옵니다. 새면 6절 순서로 갈아 끼웁니다.

## 4. 시험 발송

스킬 6단계의 `node scripts/channel-test.mjs` 를 씁니다. 화면에 응답 204(또는 200대)가 찍히고 채널에 문장이 보이면 된 것입니다.

보내는 글자 규칙:

- 한 번에 **2,000자**까지. 넘으면 거부됩니다(보고는 10줄 이내로 잡습니다).
- 줄바꿈은 그대로 살아납니다. 표는 살아나지 않습니다 — 한 줄에 한 항목으로 씁니다.
- 짧은 시간에 여러 번 보내면 잠시 막힙니다. 시험은 한 번씩만 합니다.

## 5. 안 올 때 — 이 순서로 봅니다

1. 채널에 직접 글을 써 봅니다. 써지면 디스코드 쪽은 정상입니다.
2. 주소를 **끝까지** 복사했는지 봅니다(중간에 잘리는 일이 가장 많습니다).
3. 시험 발송의 응답 번호를 봅니다.
   - 401·404 — 주소가 틀렸거나 웹후크가 삭제됐습니다. 2절을 다시 합니다.
   - 400 — 보내는 내용의 모양이 틀렸습니다. 시험 스크립트를 그대로 쓰면 나지 않습니다.
   - 429 — 너무 자주 보냈습니다. 1~2분 뒤 한 번만 다시 합니다.
   - 응답이 아예 없음 — 회사 네트워크가 막고 있을 수 있습니다. 폰 테더링으로 한 번 시험해 봅니다.
4. 채널을 지웠거나 서버에서 나갔는지 봅니다. 채널을 지우면 그 웹후크도 같이 죽습니다.

## 6. 주소가 샜을 때

1. 채널 편집 → 연동 → 웹후크 → 해당 웹후크 **삭제**. 이 순간 옛 주소는 죽습니다.
2. 2절로 새 웹후크를 만들고, `.env.local` 과 Supabase 비밀 저장의 값을 **둘 다** 바꿉니다.
3. `company/channel.md` 의 갈아 끼운 기록에 날짜를 적습니다.

## 7. 알아 두면 편한 것

- 폰 디스코드에서 그 채널만 알림을 켜 두면 폰 알림으로 받습니다(서버 이름 길게 누르기 → 알림 설정).
- 보고가 많아지면 채널을 나누지 말고 **보내는 항목을 줄입니다.** 채널이 늘면 아무 채널도 안 보게 됩니다.
- 파일(백업 파일 등)도 같은 주소로 올릴 수 있지만, **고객 정보가 든 파일은 올리지 않습니다.** 회사 밖 서비스입니다.
