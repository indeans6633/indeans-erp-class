## 8. 비밀 취급 약속

- `.env.local` 은 커밋하지 않는다(`git check-ignore -v .env.local` 확인: 예 / 아니오).
- 앱에는 공개용 키(`anon`/`publishable`)만 넣는다. 비밀 키(`service_role`/`secret`)는 어디에도 넣지 않는다.
- 데이터베이스 비밀번호 보관 위치: <비밀번호 관리 앱 / 금고> (값은 여기에 적지 않는다).
- 키가 새면: 대시보드에서 새로 발급 → `.env.local` 과 Vercel 환경 변수 둘 다 교체 → 다시 배포.
- 고정 검사(`npm run check`)가 파일에 적힌 비밀값을 찾으면 막는다(G5). 막히면 값을 지우고 새로 발급한다.
