# 우리 앱 디자인 방향

> 작성: indeans-erp-design · {날짜} · v{번호}
> 절 제목과 순서를 바꾸지 않는다. `indeans-erp-draft`와 화면 감독 에이전트가 이 문서를 읽는다.

## 고른 조합

| 항목 | 값 |
|---|---|
| 화면 구조 | {목록·표형 / 진행 보드형 / 카드·상세형} (`{list / board / card}`) |
| 색 방향 | {남색 / 차콜 / 녹색 / 갈색} (`{navy / charcoal / green / brown}`) |
| 색 설정 파일 | `src/styles/tokens.css` (원본 `.owner/design/tokens/{조합}.css`) |
| 고른 날 | {날짜} |

## 이 구조를 고른 이유

대표가 한 말을 그대로 적는다. 다음 회차에 "왜 이걸 골랐지"가 나올 때 여기를 읽는다.

- {예: 하루에 같은 목록을 여러 번 보신다고 하셔서}
- 고객이 직접 여는 화면이 있는가: {예 / 아니오}
- 주로 쓰는 기기: {휴대폰 / PC / 태블릿 / 섞여 있음}

## 이 색을 고른 이유

- {예: 간판·명함이 남색이라서}
- 로고 색을 강조색으로 그대로 쓰지 않은 이유(해당될 때만): {글자 대비}

## 바꾸면 안 되는 것

이 줄들은 화면을 고칠 때마다 지켜야 한다. 감독 에이전트가 이 목록으로 본다.

- 강조색은 **하나**다(`--primary`). 두 번째 강조색을 더하지 않는다.
- 강조색이 쓰인 곳은 화면당 두 군데 이하. 대개 버튼 하나와 선택된 줄 하나다.
- 빨강(`--danger`)은 삭제처럼 되돌릴 수 없는 행동에만. 경고·주의에 쓰지 않는다.
- 글자 크기 4종 이하(`--fs-title`·`--fs-body`·`--fs-label`·`--fs-meta`), 굵기 3종 이하.
- 여백은 `--sp-1`~`--sp-6` 값만 쓴다.
- 그림자·그라데이션·둥근 아이콘 배경·장식 이모지를 넣지 않는다.
- 색·글자 크기를 화면 파일에 직접 적지 않는다. 항상 `var(--…)`로 쓴다.
- 누르는 곳 높이는 {40}px 이상(카드·상세형은 52px 이상).
- 표·격자의 모든 열은 `minmax(0, …)`로 쓴다.
