## 실행하는 법

처음 한 번만:

```
npm install
```

매번:

```
npm run dev
```

터미널에 나오는 주소(`http://localhost:...`)를 브라우저에서 연다. 멈추려면 터미널에서 `Ctrl + C`.

## 폴더 구조

```
company/            회사 문서 — 인터뷰 결과. 앱을 고칠 때 여기를 먼저 고친다
  profile.md        회사 소개·관리 단위
  flows.md          업무 흐름·단계
  structure.md      화면 3개·적는 항목·이번에 만들지 않을 것
  scope.md          회차 범위·성공 기준
  design.md         고른 디자인(구조·스타일·색·밝기·디자인 코드)
  screens.md        화면별 설계 선언(목적·주 사용자·기기·가장 중요한 행동·쓰지 않을 것)
src/
  screens/          화면 3개
  data/sample.ts    예시 데이터 (실제 고객 정보 금지)
  lib/storage.ts    브라우저 저장
  styles/tokens.css 색·글꼴·간격 (디자인 코드: {design.code})
  styles/base.css   공통 바탕 · styles/layout.css 고른 구조의 뼈대
course/             회차 자료
reports/            작업 보고서(회차마다 쌓인다)
.owner/             진행 기록·상태 문서·검수 훅·디자인 선택창
```

## 고치고 싶을 때

AI에게 이렇게 말한다.

```
company/structure.md 를 읽고, 목록 화면에 {무엇}을 한 줄 더 보이게 해 줘.
고치기 전에 지금 상태를 커밋해 두고, 고친 뒤에 무엇이 바뀌었는지 알려 줘.
```

**화면을 먼저 고치지 말고 `company/` 문서를 먼저 고친다.** 문서와 화면이 달라지면 다음 회차 작업이 엉킨다.

## 되돌리고 싶을 때

```
git status
git restore .
```

이미 저장(커밋)한 뒤라면 AI에게 "마지막으로 잘 되던 커밋으로 되돌려 줘"라고 말한다.
