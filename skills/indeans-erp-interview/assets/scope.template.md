## 성공 기준 (대표가 직접 확인할 것)

### 1회차 — 초안

- [ ] 목록 화면에서 예시 데이터가 보인다.
- [ ] 새로 하나 만들어서 목록에 늘어나는 것을 봤다.
- [ ] 상태를 바꿨더니 목록의 표시가 바뀌었다.
- [ ] 브라우저를 새로고침해도 방금 넣은 것이 그대로 있다.
- [ ] 오늘 현황 화면이 "지금 무엇을 해야 하는지"를 말해 준다.
- [ ] 휴대폰 크기(가로 360)에서 글자가 잘리거나 가로로 밀리지 않는다.
- [ ] 작업 보고서를 받아 보고 무엇이 바뀌었는지 읽었다.

### 2회차 — 실제 저장과 주소

- [ ] 직원 계정으로 입력한 것이 대표 화면에도 보인다.
- [ ] 다시 접속해도 저장된 내용이 그대로 있다.
- [ ] 인터넷 주소로 열린다.
- [ ] 백업을 한 번 받아 두었다.

### 3회차 — 운영 보고

- [ ] 정해진 시각에 정해진 채널로 보고가 왔다.
- [ ] 내 컴퓨터와 AI 도구를 꺼 두었는데도 왔다.

### 4회차 — 검수와 복구

- [ ] 백업에서 되돌리기를 한 번 해 봤다.
- [ ] 검수가 언제 무엇을 하는지 설명할 수 있다.
