## 몰라요 · 되묻기 두 번 뒤 채우는 기본값 (모두 `(짐작)` 으로 적고 차수 끝에 확인)

- 한 건 = 주문(납품) 하나
- 순서 = 주문 받음 → 만드는 중 → 검사 → 보냄 → 끝
- 돈 = 월말에 거래처별로
- 물건 = 재료·다 만든 물건(또는 들여온 물건)
- 아침 화면 = 오늘 나갈 것·납기 가까운 것
- 화면 모양 = 단계별 보드 또는 목록(건수에 따라)
