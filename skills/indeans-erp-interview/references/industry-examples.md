# 업종별 답 예시와 그때 정해지는 관리 단위

되묻기용 예시를 만들 때 참고한다. **여기 있는 답을 대표에게 읽어 주고 고르게 하지 않는다.** "이런 답을 하시는 분들도 있다" 정도로 한 번만 들고, 바로 "대표님 회사는 어떠세요?"로 돌아온다.

다섯 업종 모두 가상의 회사다.

---

## 1. 제조 — 주문 제작 (예: 금속 간판·가구·기계 부품)

| 질문 | 나올 법한 답 |
|---|---|
| 업종 | "주문 받아서 만들어 납품합니다" |
| 상품 | "도면 받아서 제작하는 부품이요. 같은 게 하나도 없어요" |
| 돈 | "발주서 받고 반 받고, 납품하고 반 받습니다" |
| 사람 | "사무실 2명, 공장 4명. 납품은 제가 나갑니다" |
| 도구 | "발주서는 메일, 진행은 화이트보드, 정산은 엑셀" |
| 귀찮은 일 | "어느 건이 어디까지 됐는지 매번 공장에 전화해서 물어봅니다" |

- **관리 단위: 주문(수주)** — 발주서 한 장이 한 건.
- 첫 흐름 후보: 발주 접수 → 제작 → 납품 → 잔금
- 단계 증거: 도면 파일, 제작 완료 사진, 납품확인서
- 화면이 이렇게 갈린다: 밖(공장)에서 상태를 바꾸므로 **모바일 화면이 처음부터 필요**하다.

## 2. 방문 서비스 — 정기·출동 (예: 청소·정비·점검)

| 질문 | 나올 법한 답 |
|---|---|
| 업종 | "사무실이나 가정 방문해서 청소합니다" |
| 상품 | "정기 계약이 반, 단발 요청이 반이요" |
| 돈 | "정기는 월말에 한 번, 단발은 끝나고 바로" |
| 사람 | "제가 배정하고, 기사님 3명이 나갑니다" |
| 도구 | "일정은 구글 캘린더, 보고는 단톡방 사진" |
| 귀찮은 일 | "누가 어디 갔는지, 갔다 왔는지 단톡방을 위로 올려가며 찾습니다" |

- **관리 단위: 방문(작업)** — 날짜+장소+담당 하나가 한 건.
- 첫 흐름 후보: 요청 접수 → 배정 → 방문 완료 → 청구
- 단계 증거: 배정 확인, 완료 사진, 고객 확인
- 화면이 이렇게 갈린다: "오늘 현황" 화면이 **오늘 나가는 방문 목록**이 된다. 세 화면 중 가장 많이 본다.

## 3. 유통 — 온라인 판매·도매

| 질문 | 나올 법한 답 |
|---|---|
| 업종 | "스마트스토어랑 도매로 생활용품 팝니다" |
| 상품 | "품목이 200개쯤 되고, 잘 나가는 건 20개 정도요" |
| 돈 | "온라인은 정산일에 들어오고, 도매는 월말 결제" |
| 사람 | "포장 2명, 제가 발주·CS" |
| 도구 | "주문은 각 쇼핑몰 관리자, 재고는 엑셀" |
| 귀찮은 일 | "재고가 엑셀이랑 실제가 안 맞아서 품절 사고가 납니다" |

- **관리 단위: 두 개로 보인다.** 질문 13의 되묻기("몇 건 했다고 할 때 뭘 세세요?")로 가른다. 대개 **주문**이 관리 단위, **품목**은 그 안에 딸린 것.
- 첫 흐름 후보: 주문 확인 → 포장 → 발송 → 정산 확인
- 단계 증거: 송장번호, 발송 완료 표시
- 화면이 이렇게 갈린다: 건수가 많으므로 **검색과 기간 필터가 1회차부터 필요**하다.

## 4. 예약업 — 시간 단위 (예: 스튜디오·교습소·상담실)

| 질문 | 나올 법한 답 |
|---|---|
| 업종 | "사진 스튜디오 운영합니다" |
| 상품 | "촬영 상품이 다섯 가지쯤 있고, 시간대로 예약을 받습니다" |
| 돈 | "예약금 받고, 당일에 나머지" |
| 사람 | "저랑 실장님 둘, 성수기엔 보조 부릅니다" |
| 도구 | "예약은 네이버, 나머지는 노트" |
| 귀찮은 일 | "예약 변경·취소가 문자로 오는데 옮겨 적다가 겹치기가 납니다" |

- **관리 단위: 예약** — 날짜·시간·고객 하나가 한 건.
- 첫 흐름 후보: 예약 접수 → 예약금 확인 → 당일 진행 → 결과물 전달
- 단계 증거: 예약금 입금 확인, 당일 체크, 전달 완료
- 화면이 이렇게 갈린다: "오늘 현황"이 **오늘 시간표**가 된다. 목록은 날짜순이 기본.

## 5. 전문 사무 — 의뢰 단위 (예: 세무·노무·설계 사무소)

| 질문 | 나올 법한 답 |
|---|---|
| 업종 | "기장하고 신고 대행합니다" |
| 상품 | "월 기장이 기본이고, 신고 시즌에 건별로 몰립니다" |
| 돈 | "기장료는 매달, 신고는 건별" |
| 사람 | "저랑 직원 3명이 담당 나눠서 봅니다" |
| 도구 | "고객사 목록은 엑셀, 진행은 각자 알아서" |
| 귀찮은 일 | "마감일에 누가 뭘 아직 안 냈는지 파악이 안 됩니다" |

- **관리 단위: 두 층으로 보인다.** 고객사(계속 있는 것)와 의뢰·신고 건(매번 생기는 것). 1회차에는 **매번 생기는 쪽**을 관리 단위로 잡는다. 계속 있는 쪽은 2회차에 붙인다.
- 첫 흐름 후보: 자료 요청 → 자료 수령 → 작성 → 제출 → 통보
- 단계 증거: 자료 수령 표시, 제출 접수번호
- 화면이 이렇게 갈린다: 마감일이 핵심이므로 "오늘 현황"이 **기한 임박 목록**이 된다.

---

## 6. 시공 — 현장 단위 (예: 인테리어·설비·전기공사)

| 질문 | 나올 법한 답 |
|---|---|
| 업종 | "아파트 리모델링 합니다" |
| 상품 | "전체 리모델링이요. 30평대가 제일 많아요" |
| 돈 | "계약금 받고, 중간에 한 번, 끝나고 잔금이요" |
| 사람 | "저랑 디자이너·현장 관리·사무 넷이요. 시공은 다 외주 팀입니다" |
| 도구 | "견적은 엑셀, 일정은 카톡, 사진은 각자 폰" |
| 귀찮은 일 | "어느 현장이 어디까지 갔는지 매일 전화로 물어봅니다" |

> **이 단계 이름을 문서에 옮겨 적지 않는다 — 대표가 부른 단어 그대로 쓴다.** 이 절은 다른 어느 절보다 실제 답과 비슷하게 나오기 때문에 그대로 베끼기 쉽다. 대표가 "철거", "도배·마루", "준공청소"라고 부르면 문서·화면·코드의 라벨은 전부 그 말이다. 아래 줄은 **되묻기용 예시일 뿐 정답이 아니다.**

- **관리 단위: 현장** — "이번 달 현장 몇 개"라고 셀 때의 그 현장.
- 첫 흐름 후보: 착공 준비 → 철거·설비 → 목공·마감 → 준공
- 단계 증거: 단톡방 사진, 자재 발주서, 고객 열쇠 인수
- 화면이 이렇게 갈린다: **한 건이 6~8주 가므로 월 건수는 적은데 동시에 열려 있는 건이 많다.** 검색은 필요 없고 **상태(공정)별 묶어 보기**가 필요하다. 그래서 질문 4(월 건수 구간) 뒤에 질문 14("지금 동시에 열려 있는 ○○이 몇 개쯤인가요?")를 꼭 이어 묻는다.
- 끝나는 시점이 둘로 보인다: 준공(공사 끝)과 잔금 입금(거래 끝). 대표가 "준공이 끝"이라고 답해도 뒤 회차에 다시 갈릴 자리다.

---

## 관리 단위를 고르는 세 가지 신호

업종이 무엇이든 아래로 판단한다.

1. **세는 것** — "이번 달 몇 건 했다"고 할 때 세는 것.
2. **한 줄로 늘어놓을 수 있는 것** — 목록 화면에 한 줄씩 들어갈 수 있어야 한다.
3. **상태가 변하는 것** — 시작해서 끝나는 것. 끝나지 않고 계속 있는 것(고객사·품목·직원)은 관리 단위가 아니라 **거기에 딸린 정보**다.

세 신호가 서로 다른 것을 가리키면 1번(세는 것)을 따른다.

## 업종 말로 바꿔 부르기

앱에서 쓰는 이름은 대표가 부르는 말을 그대로 쓴다. 예:

| 일반 말 | 회사 말 예 |
|---|---|
| 목록 | 수주 대장 / 예약 현황 / 의뢰 목록 |
| 상세 | 카드 / 건별 내역 / 지시서 |
| 오늘 현황 | 오늘 나가는 것 / 오늘 시간표 / 이번 주 마감 |
| 상태 | 진행 / 단계 / 어디까지 |

`profile.md`와 `scope.md`에 이 대응표를 적어 두면 다음 회차 스킬이 같은 말을 쓴다.
