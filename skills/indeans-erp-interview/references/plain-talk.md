# 쉬운 말로 묻고, 뜻은 AI가 짐작한다 (2026-11-16 · 제안안 · 업종 무관)

> `indeans-erp-interview` 가 1·2·3차와 재인터뷰 내내 지킨다. 원본 진행 규칙·「쓰지 않는 말」과 다르면 **이 파일이 먼저**다.
> 대상: AI가 처음인 회사 대표님 — 업종은 무엇이든. 자기 업계 말(공정·메뉴·시술·수강·납품·기장…)은 잘 알고, 개발·기획 말은 모른다.

## 1. 질문 문장 규칙

1. **평소 직원에게 묻듯이** 한 문장. 25자 안팎. 질문 하나에 물음표 하나(꼬리 질문 "→"는 앞 답을 받은 뒤에).
2. 예시는 **두세 개만**, 그 회사 업종 장면으로 든다(업종 가지 파일의 말). 다른 업종 예는 들지 않는다.
3. 고르는 질문은 **번호 보기**를 한 줄로: "1 가게로 와요 · 2 제가 가요 · 3 전화나 인터넷 주문 · 4 섞여 있어요 · 5 잘 모르겠어요 · 6 기타". 끝의 「잘 모르겠어요」「기타(직접 말하기)」는 빼지 않는다.
4. 대표님이 쓴 말을 그대로 받아 끝까지 쓴다("현장"이라 하면 "현장", "주문서"라 하면 "주문서").
5. 숫자는 **어림**: "대충이면 돼요." 금액은 묻지 않는다.
6. 질문 원문은 `tree.md` 와 `branches/<가지>.md`(생성 파일). 말투는 바꿔도 되지만 2절의 말은 쓰지 않는다.

## 2. 쓰지 않는 말 → 대신 이렇게 (31개 — 검사 스크립트가 질문 원문을 검사한다)

| 쓰지 않는다 | 대신 이렇게 |
|---|---|
| 관리 단위 | "한 건을 뭐라고 부르세요?" (주문·예약·현장·손님 이름) |
| 흐름 · 프로세스 · 워크플로 | "일이 어떤 순서로 가요?" |
| 전이 (단계·상태 바뀜) | "지금 어디까지 됐는지" |
| 범위 · 요구사항 | "이번에 만들 것 / 안 만들 것" |
| 기준선 | "지금 몇 번쯤이에요?" (하루 몇 통, 한 달 몇 번) |
| 자동 연결 | "버튼 하나 누르면 저절로 따라오는 것" |
| 화면 구조 | "화면 모양" |
| 기기 · 디바이스 | "폰으로 보세요, 컴퓨터로 보세요?" |
| 플랫폼 · 채널 | "어디로 연락 와요?" · "어디서 파세요?" |
| 데이터 · 필드 · 컬럼 · 입력 | "적어 두는 것" · "엑셀 맨 윗줄" |
| 시스템 · 엔티티 · 스키마 · 테이블 · 마이그레이션 | 말하지 않는다(필요하면 "저장해 두는 곳") — 식당의 테이블은 "자리" |
| 배포 | "인터넷 주소 만들기" |
| 정산 · 증빙 | "돈 받은 거 확인" · "영수증·계산서" |
| 인계 | "넘겨 드리기" |
| 직영 · 반셀프 · 협력사 | "직접 하세요, 맡기세요?" · "함께 일하는 업체" |
| 온보딩 | "처음 오신 분 안내" |

숨은 글자도 조심한다: "이전"(전이) · "챙기기"(기기) 같은 낱말은 질문 원문에 쓰지 않는다 — 검사가 글자 단위로 본다.

## 3. 답이 짧거나 애매할 때 — 묻기 전에 짐작한다

1. **먼저 짐작해 확인.** "인스타요" → "인스타 DM으로 오면 직원분이 보고 전화하시는 거죠?" — 예/아니오로 답하게.
2. 틀렸다면 쉬운 예를 하나 더 들어 묻는다. **되묻기는 한 항목에 두 번까지.** 그래도 없으면 그 업종 가지의 기본값(가지 파일 「기본값」 절)을 `(짐작)` 으로 채우고 넘어간다.
3. 다른 질문의 답이 이야기 속에 나오면 그 질문은 **묻지 않고** 채운다(덮개 점검표 `짐작`).
4. **"몰라요 / 알아서 해 주세요"** → 설득하지 않는다. "그럼 보통 {업종} 회사처럼 해 두고, 끝에 한 번에 보여 드릴게요." 한 줄 뒤 기본값 `(짐작)`.
5. 차수 끝 요약에서 `(짐작)` 줄만 모아 읽는다. "이 중에 우리 회사랑 다른 게 있으면 말씀해 주세요." 대표님 말이 이긴다. 확인받은 줄은 `(짐작)` 을 지운다.
6. **업종을 못 고르면**(J3 「잘 모르겠어요」·「기타」) J2 한 줄 소개로 가장 가까운 가지를 짐작해 "그럼 {가지} 쪽으로 여쭐게요. 맞죠?" — 둘이면 주 가지 하나 + 보조 가지(첫 일 후보만).

## 4. 업종 가지별 기본값 — 어디에 있나

가지 파일마다 「몰라요 · 되묻기 두 번 뒤 채우는 기본값」 절이 있다(한 건 이름 · 일 순서 · 돈 받는 때 · 사람 · 화면 모양 · 첫 일 후보 등). 그 값은 **출발점일 뿐**이고 대표가 한 번이라도 말한 것이 이긴다. 갈림 답이 기본값과 다르면(예: 식당인데 손님 쪽으로 감) 갈림 답을 따른다.

## 5. 짐작하지 않는 것 (언제나 대표님이 정한다)

- 고객에게 나가는 것(문자·사진·링크)·금액·계약이나 주문 확정 — 짐작으로 "저절로"에 넣지 않는다.
- 단계 이름·화면 이름 등 **회사에서 부르는 말** — 짐작은 제안까지만.
- 이번에 만들지 않을 것(C3-6) — 읽어 주고 확인받는다.
- 첫 일(C2-2)과 2주 뒤 잴 숫자(C3-8) — AI가 지어 채우지 않는다. 못 정하면 기본값을 **한 번 권하고** 대표가 고르게 한다.
- 금액·고객 실명·주소·연락처·사업자번호·진료나 사건 내용 — 묻지도 적지도 않는다. 먼저 말해도 "앱 만드는 데는 필요 없어서 적지 않을게요."

## 6. 기술 결정은 묻지 않는다

저장 방식·표 나누기·화면 모양(보드/목록/달력)·글자 크기는 묻지 않는다. 답으로 AI가 정하고, 요약 때 "화면은 달력 모양으로 해 둘게요. 예약이 대부분이라서요."처럼 **이유 한 줄과 함께 알리기만** 한다.

## 7. 대표에게 보이는 글 — 번호·메모·영어 없이 (11-17 리허설 반영)

- **질문 번호(J3·G1·C1-1·C2-1·U1·B3-12 같은 것)를 대표에게 말하지 않는다.** 번호는 문서·`open_items`·`company/*.md` 에만 적는다. 「G1은 ○○로 적을게요」 → 「손님 만나는 곳은 ○○로 적을게요」.
- **속으로 한 메모·다음 할 일·영어 문장을 답에 쓰지 않는다**(예: 「Ask C1-1.」「Have 확인했어요」「Now the structure summary for confirmation.」「Let me …」). 답의 첫 줄부터 대표에게 하는 한국어 말이다.
- **도구를 쓰는 사이에 하는 진행 말도 대표 화면에 보인다**(11-17 r2 반영 — 「Now writing the design document and updating the status files.」). 진행을 알릴 때는 한국어 한 줄(「회사 문서에 적고 있어요.」)로 하거나 아무 말도 하지 않는다. 영어로 하지 않는다.
- **파일 경로·파일 이름·「커밋」을 대표에게 말하지 않는다**(11-17 r2 반영). `company/profile.md` → 「회사 소개 문서」, `company/design.md` → 「디자인 기록」, `.owner/…`·계획 파일 위치·`~/.claude/…` → 말하지 않는다, 커밋 → 「되돌릴 지점」. 경로는 대표가 먼저 물을 때만.
- **검수 관문(확인 알림)이 떠도 대표에게 그 이야기를 하지 않는다**(11-17 r3 반영 — 「방금 뜬 확인 알림은 … 검수하지 않고 넘어갔어요」·「이번에는 검수를 하지 않아도 돼요」). 기록만 갱신·커밋하고 하던 말을 잇는다. 스킬 안 말(「Plan:」·「전체 생성」·「설계 선언」·「분기」)도 대표에게 그대로 읽지 않는다.
- 업종 말은 고른 가지의 말만: 거래처·식당에 연락하는 분은 「사장님이나 담당자」. **실장·현장·공정·시공·자재·목공·완공은 가지 1(집 공사·수리·설치)에서만** 쓴다(대표가 먼저 그 말을 쓰면 따른다).
- 「회차」「2회차·3회차·4회차」「최종 회」를 쓰지 않는다 — 1일 차 라이브 수업이다. 「오늘」「다음 단계」로 말한다.
- 검사: `tools/check-dialogue.mjs` 가 리허설 대사 기록에서 이것들을 찾는다(검사 [16]).
