# 1. 제조·가공 — 질문 팩

> 목차·공통 규칙은 `../industry-taxonomy.md`. 칸을 메뉴처럼 읽어 주지 않는다. 질문은 이 업종의 말로 쓴 원문이다 — 대표가 다른 말을 쓰면 대표의 말로 바꿔 묻는다. 모든 칸은 가상의 일반 서술이다.

### 1.1 주문 제작

예: 금속 가공 · 목공 가구 · 간판 · 기계 부품 · 인쇄물

- **이 업종의 말**: 한 건 → 주문(수주) · 들어옴 → 견적 요청·발주서·도면 · 단계 → 공정(재단·가공·조립·도장 같은 회사 말) · 끝 → 납품 · 고객 → 거래처(발주처)
- **관리 단위**: 주문(수주) · 작업지시. 두 층: 거래처(계속 있음) / 주문(매번 생김) → 주문이 관리 단위, 거래처는 고르기 칸.
- **첫 흐름 후보**: 발주서 받음 → 납품 확인 · 견적 요청 → 수주 · **구조 추천**: board — 공정 4~5개를 여러 사람이 이어받아 "지금 누구 차례인가"를 자주 묻는다
- **증거 예**: 도면 확정 표시 · 공정별 완료 사진 · 검사 표시 · 납품확인서 서명 · **막히는 곳**: 어느 주문이 어디까지 됐는지 작업장에 전화해 묻는다 · 납기가 코앞에 와서야 늦은 걸 안다 · 도면이 바뀐 걸 작업장이 모른다

**1차 세부**
1. "매번 도면(사양)이 다른가요, 같은 것을 되풀이해 만드시나요?"
2. "재료는 주문이 오면 사시나요, 미리 사 두시나요?"
3. "납품은 직접 가져다주시나요, 찾으러 오시나요?"

**2차 흐름**
1. "견적 요청이 오면 무엇을 보고 견적을 내세요?" [견적 · 시작]
2. "발주서나 도면을 받으면 누가 먼저 보나요?" [주문 · 시작·담당]
3. "작업장에서는 어떤 순서로 만드나요? 회사에서 부르시는 공정 이름 그대로요." [주문 · 단계]
4. "한 공정이 끝났다는 건 무엇으로 확인하세요?" [주문 · 증거]
5. "도면이 중간에 바뀌면 작업장에는 어떻게 알리세요?" [주문 · 되돌리기]
6. "재료가 모자라거나 늦게 오면 일정은 어떻게 하세요?" [주문 · 안 되는 날]
7. "납품이 끝났다는 건 무엇으로 남기세요? 납품확인서인가요, 사진인가요?" [주문 · 끝·증거]
8. "불량이 나와 다시 만드는 일은 어떻게 처리하세요?" [주문 · 되돌리기]

**3차 화면·항목 제안**
1. "주문 목록 한 줄에 거래처·품명·수량·납기·지금 공정을 보이면 될까요?" [3-1]
2. "주문 한 건에는 거래처·품명·수량·납기·도면 파일 이름·담당·지금 공정·메모를 적으면 될까요?" [3-3]
3. "아침 첫 화면에 이번 주 납기와 공정이 늦어지는 주문이 보이면 될까요?" [3-2]
4. "거래처는 고르기 칸으로 두고, 거래처만 따로 보는 목록은 다음으로 미뤄도 될까요?" [3-7]

### 1.2 반복 생산

예: 식품 제조 · 화장품 · 생활용품 · 포장재

- **이 업종의 말**: 한 건 → 생산(한 번 만드는 묶음)·출고 · 묶음 → 로트(같은 날 만든 묶음) · 재료 → 원재료·부자재 · 끝 → 출고
- **관리 단위**: 생산 · 출고 · 원재료 발주. 두 층: 제품·원재료(계속 있음) / 생산·출고(매번 생김) → 생산 또는 출고가 관리 단위, 제품은 고르기 칸.
- **첫 흐름 후보**: 생산 계획 → 출고 완료 · 원재료 발주 → 입고 · **구조 추천**: list — 날짜·제품·수량을 줄로 견주는 일이 많다
- **증거 예**: 생산 일지 · 검사 표시 · 출고 전표 · 입고 확인 · **막히는 곳**: 재고 숫자가 실제와 다르다 · 원재료가 떨어진 걸 늦게 안다 · 유통기한 임박을 놓친다

**1차 세부**
1. "같은 제품을 날마다 만드시나요, 주문이 모이면 한 번에 만드시나요?"
2. "만든 것은 쌓아 두고 파시나요, 바로 내보내시나요?"
3. "유통기한이나 만든 날 묶음(로트)을 따로 챙기시나요?"

**2차 흐름**
1. "무엇을 얼마나 만들지는 언제, 누가 정하세요?" [생산 · 시작·담당]
2. "원재료는 무엇이 보이면 주문하세요?" [원재료 발주 · 시작]
3. "만드는 날에는 어떤 순서로 일하세요? 회사에서 부르시는 이름 그대로요." [생산 · 단계]
4. "다 만든 것은 무엇으로 확인하고 남기세요? 생산 일지나 검사 표시 같은 것이요." [생산 · 끝·증거·도구]
5. "재고는 언제, 어디에 세어 적으세요?" [재고 · 도구]
6. "출고는 무엇을 받으면 하세요? 주문서인가요, 전화인가요?" [출고 · 시작]
7. "불량이 나오거나 유통기한이 지난 것은 어디에 적고 어떻게 처리하세요?" [생산 · 되돌리기]
8. "기계가 서거나 재료가 안 들어와서 못 만드는 날은 어떻게 하세요?" [생산 · 안 되는 날]

**3차 화면·항목 제안**
1. "생산 목록 한 줄에 날짜·제품·수량·로트·검사 여부를 보이면 될까요?" [3-1]
2. "생산 한 건에는 날짜·제품·수량·로트·쓴 원재료·담당·검사 결과를 적으면 될까요?" [3-3]
3. "아침 첫 화면에 오늘 만들 것과 오늘 나갈 것이 보이면 될까요?" [3-2]
4. "제품·원재료는 고르기 칸으로 두고, 재고 숫자 계산은 다음으로 미뤄도 될까요?" [3-7]

### 1.3 위탁 생산 (OEM)

예: 남의 상표로 만들어 납품 · 시제품·샘플 제작

- **이 업종의 말**: 한 건 → 의뢰(프로젝트) · 고객 → 의뢰사(상표를 가진 회사) · 단계 → 샘플·확정·양산·납품 · 증거 → 샘플 승인
- **관리 단위**: 의뢰 · 양산 발주. 두 층: 의뢰사(계속 있음) / 의뢰(매번 생김) → 의뢰가 관리 단위.
- **첫 흐름 후보**: 의뢰 접수 → 샘플 승인 → 양산 납품 · **구조 추천**: board — 샘플·확정·양산처럼 단계가 길고 기다리는 칸이 핵심이다
- **증거 예**: 사양서 · 샘플 발송 기록 · 승인 회신 · 검수 결과 · 납품 확인 · **막히는 곳**: 샘플 승인을 기다리다 일정이 밀리는데 누가 기다리는지 모른다 · 의뢰사마다 요구가 달라 빠뜨린다

**1차 세부**
1. "의뢰사가 사양을 정해서 주나요, 같이 만들어 가시나요?"
2. "양산 전에 샘플이 몇 번쯤 오가나요?"
3. "의뢰사 한 곳에 제품이 여러 개 걸려 있나요?"

**2차 흐름**
1. "의뢰가 들어오면 처음에 무엇을 받으세요?" [의뢰 · 시작]
2. "샘플은 누가 만들고 보내세요?" [의뢰 · 담당]
3. "샘플이 통과됐다는 건 무엇으로 확인하세요?" [의뢰 · 증거]
4. "샘플이 퇴짜를 맞으면 어디서부터 다시 하세요?" [의뢰 · 되돌리기]
5. "양산은 어떤 순서로 가나요? 회사에서 부르시는 이름 그대로요." [의뢰 · 단계]
6. "의뢰사가 대 주는 포장재·원료가 늦게 오면 어떻게 하세요?" [의뢰 · 안 되는 날]
7. "납품이 끝났다는 건 무엇으로 남기세요?" [의뢰 · 끝]
8. "의뢰사에 진행 상황은 언제, 어떻게 알려 드리세요?" [의뢰 · 정산·후속]

**3차 화면·항목 제안**
1. "의뢰 목록을 단계별로 묶어서, 한 줄에 의뢰사·제품·납기를 보이면 될까요?" [3-1]
2. "의뢰 한 건에는 의뢰사·제품·사양서 파일 이름·샘플 몇 번째·승인 날짜·양산 수량·납기를 적으면 될까요?" [3-3]
3. "아침 첫 화면에 승인을 기다리는 샘플과 이번 주 납기가 보이면 될까요?" [3-2]
4. "의뢰사에 보내는 진행 알림은 운영 보고 단계로 미뤄도 될까요?" [3-7]

### 1.4 맡긴 물건 가공

예: 도장·도금 · 수선·리폼 공장 · 장비 수리 입고

- **이 업종의 말**: 한 건 → 입고(접수) · 물건 → 맡긴 물건 · 끝 → 출고(인계) · 고객 → 맡긴 곳(업체·개인)
- **관리 단위**: 입고 · 접수 번호. 두 층: 맡긴 곳(계속 있음) / 입고(매번 생김) → 입고가 관리 단위.
- **첫 흐름 후보**: 입고 접수 → 출고(인계) · **구조 추천**: board — 입고·작업·완료·인계 칸마다 쌓인 수를 본다
- **증거 예**: 입고 사진 · 작업 완료 표시 · 인수 서명 · **막히는 곳**: 맡긴 물건이 어디 있는지·언제 되는지 묻는 전화가 많다 · 다 됐는데 찾아가라는 연락을 빠뜨린다

**1차 세부**
1. "물건이 들어올 때 무엇을 받아 적으세요?"
2. "다 되면 찾으러 오시나요, 보내 드리나요?"
3. "작업 전에 견적이나 날짜를 먼저 알려 드리나요?"

**2차 흐름**
1. "물건이 들어오면 무엇부터 하세요? 사진이나 번호를 붙이시나요?" [입고 · 시작·증거]
2. "작업 전에 맡긴 분께 무엇을 확인받으세요?" [입고 · 단계]
3. "작업은 어떤 순서로 가나요? 회사에서 부르시는 이름 그대로요." [입고 · 단계]
4. "작업은 누가 맡나요? 물건마다 정해지나요?" [입고 · 담당]
5. "다 됐다는 건 무엇으로 확인하세요?" [입고 · 증거]
6. "찾아가셨다는 건 무엇으로 남기세요?" [입고 · 끝] — 이어서: "다 된 것은 어떻게 알려 드리세요?"
7. "작업 중에 부품이 없거나 손상이 더 발견되면 어떻게 하세요?" [입고 · 안 되는 날·되돌리기]
8. "오래 안 찾아가는 물건은 어떻게 하세요?" [입고 · 안 되는 날]

**3차 화면·항목 제안**
1. "입고 목록 한 줄에 접수 번호·맡긴 곳·물건·약속한 날·지금 단계를 보이면 될까요?" [3-1]
2. "입고 한 건에는 접수 번호·맡긴 곳·물건·요청 내용·입고 사진·약속한 날·담당을 적으면 될까요?" [3-3]
3. "아침 첫 화면에 오늘 약속한 것과, 다 됐는데 안 찾아간 것이 보이면 될까요?" [3-2]
4. "다 됐다는 연락 보내기는 운영 보고 단계로 미뤄도 될까요?" [3-7]

### 1.5 공방·소량 수제품

예: 가죽 · 도자기 · 수제 식품 · 향초 · 액세서리

- **이 업종의 말**: 한 건 → 주문 · 만들기 → 제작 · 파는 곳 → 온라인 스토어·메시지·장터 · 끝 → 발송(전달)
- **관리 단위**: 주문. 두 층: 작품(제품 — 계속 있음) / 주문(매번 생김) → 주문이 관리 단위, 작품은 고르기 칸.
- **첫 흐름 후보**: 주문 접수 → 발송 완료 · 재료 주문 → 입고 · **구조 추천**: list — 혼자 또는 소수가 날짜순으로 하나씩 처리한다
- **증거 예**: 입금 확인 · 완성 사진 · 송장 번호 · **막히는 곳**: 주문이 여러 곳(메시지·온라인)으로 흩어져 들어와 빠뜨린다 · 제작 순서가 머릿속에만 있다

**1차 세부**
1. "만들어 두고 파시나요, 주문받고 만드시나요?"
2. "주문은 주로 어디로 들어오나요? 온라인 스토어·메시지·장터 중에요."
3. "주문마다 이름 새기기나 색 고르기 같은 요청이 붙나요?"

**2차 흐름**
1. "여러 곳으로 들어온 주문은 어디에 한데 모으세요?" [주문 · 시작·도구]
2. "주문받고 나서 맨 먼저 무엇을 확인하세요? 입금인가요, 요청 사항인가요?" [주문 · 단계]
3. "만드는 순서는 어떻게 정하세요? 받은 순서인가요, 보낼 날 순서인가요?" [주문 · 단계]
4. "다 만들었다는 건 무엇으로 남기세요?" [주문 · 증거]
5. "보낸 것은 무엇으로 확인하세요?" [주문 · 끝] — 이어서: "송장 번호는 어디에 적으세요?"
6. "재료가 떨어져서 못 만드는 날은 어떻게 하세요?" [주문 · 안 되는 날]
7. "교환·환불 요청은 어떻게 받고 처리하세요?" [주문 · 되돌리기]

**3차 화면·항목 제안**
1. "주문 목록 한 줄에 받은 날·주문한 곳·작품·보낼 날을 보이면 될까요?" [3-1]
2. "주문 한 건에는 받은 날·주문한 곳·작품·수량·요청 사항·입금 확인·송장 번호를 적으면 될까요?" [3-3]
3. "아침 첫 화면에 오늘 만들 것과 오늘 보낼 것이 보이면 될까요?" [3-2]
4. "작품은 고르기 칸으로 두고, 재료 재고는 다음으로 미뤄도 될까요?" [3-7]
