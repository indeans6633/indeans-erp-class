# 3. 도소매·유통 — 질문 팩

> 목차·공통 규칙은 `../industry-taxonomy.md`. 칸을 메뉴처럼 읽어 주지 않는다. 질문은 이 업종의 말로 쓴 원문이다 — 대표가 다른 말을 쓰면 대표의 말로 바꿔 묻는다. 모든 칸은 가상의 일반 서술이다.

보기: 1 온라인 판매 · 2 도매·거래처 납품 · 3 동네 매장(소매) · 4 대여(렌탈) · 5 그 밖

### 3.1 온라인 판매

예: 스마트스토어 · 자사몰 · 오픈마켓 · 수입 상품 판매

- **이 업종의 말**: 한 건 → 주문 · 파는 곳 → 판매 채널 · 끝 → 발송 · 되돌리기 → 교환·반품 · 물건 → 상품(품목)·재고 · 들여오기 → 사입·입고
- **관리 단위**: 두 층 — 상품(계속 있음) / 주문·반품·입고(매번 생김). 판매 채널 관리 화면이 주문을 이미 세고 있으면 주문은 다시 만들지 않는다 — 그 뒤에 사람이 챙기는 반품·입고·재고 맞추기에서 고른다.
- **첫 흐름 후보**: 반품 접수 → 처리 완료 · 사입 → 입고 확인 · 주문 확인 → 발송 · **구조 추천**: list — 건수가 많아 찾기와 걸러 보기가 먼저다
- **증거 예**: 송장 번호 · 발송 표시 · 반품 입고 확인 · **막히는 곳**: 재고 숫자가 실제와 안 맞아 품절 사고가 난다 · 반품·교환을 놓친다 · 채널마다 주문을 따로 본다

**1차 세부**
1. "판매하는 곳(채널)이 몇 군데인가요?"
2. "포장·발송은 직접 하시나요, 맡기시나요?"
3. "상품 가짓수는 대략 한 자리·수십·수백 중에 어디인가요?"

**2차 흐름**
1. "주문은 어디에서 확인하세요? 채널마다 따로 보시나요?" [주문 · 시작·도구]
2. "주문 확인부터 발송까지 어떤 순서로 가나요? 회사에서 부르시는 이름 그대로요." [주문 · 단계] — 이어서: "보냈다는 건 무엇으로 확인하세요?" [주문 · 끝·증거]
3. "교환·반품 요청이 오면 누가 무엇부터 하세요?" [반품 · 시작·담당]
4. "반품은 어떤 순서로 처리하세요? 회수·검수·환불 같은 회사 말 그대로요." [반품 · 단계]
5. "돌아온 물건은 무엇으로 확인하고 어디에 적으세요?" [반품 · 증거·도구]
6. "반품 처리가 끝났다는 건 무엇으로 정하세요?" [반품 · 끝] — 이어서: "회수가 늦어지거나 고객과 연락이 안 되면요?" [반품 · 안 되는 날]
7. "물건을 들여올 때(사입)는 무엇을 보고 주문하세요?" [입고 · 시작]
8. "재고는 언제, 어디에서 맞춰 보세요?" [재고 · 도구] — 이어서: "품절은 어떻게 알게 되세요?" [재고 · 안 되는 날]

**3차 화면·항목 제안**
1. "반품 목록 한 줄에 접수일·채널·상품·사유·지금 단계를 보이면 될까요?" [3-1]
2. "반품 한 건에는 접수일·채널·주문 번호·상품·사유·회수 송장·입고 확인·처리 결과를 적으면 될까요?" [3-3]
3. "아침 첫 화면에 오늘 처리할 반품과 떨어져 가는 상품이 보이면 될까요?" [3-2]
4. "채널 주문을 자동으로 가져오는 것은 이번에 만들지 않고 나중으로 미뤄도 될까요?" [3-7]

### 3.2 도매·거래처 납품

예: 식자재 납품 · 부자재 도매 · 거래처 정기 공급

- **이 업종의 말**: 한 건 → 주문·납품 · 고객 → 거래처 · 끝 → 납품(배송) · 돈 → 월말 결제·못 받은 돈(미수) · 서류 → 거래명세서
- **관리 단위**: 납품(주문). 두 층: 거래처·품목(계속 있음) / 납품(매번 생김) → 납품이 관리 단위, 거래처·품목은 고르기 칸.
- **첫 흐름 후보**: 주문 접수 → 납품 완료 · 월말 정산 확인 · **구조 추천**: list — 거래처·날짜·품목을 줄로 견준다
- **증거 예**: 거래명세서 · 납품 확인 서명 · 입금 확인 · **막히는 곳**: 거래처 주문이 전화·메시지로 와서 빠뜨린다 · 못 받은 돈 확인이 늦다

**1차 세부**
1. "거래처가 한 자리·수십·수백 중 어느 정도인가요?"
2. "정해진 날마다 같은 걸 넣으시나요, 그때그때 주문받으시나요?"
3. "배송은 직접 하시나요, 택배·화물로 보내시나요?"

**2차 흐름**
1. "거래처 주문은 어떻게 들어오나요? 전화·메시지·주문서 중에요." [납품 · 시작]
2. "받은 주문은 누가 어디에 옮겨 적으세요?" [납품 · 담당·도구]
3. "출고 준비는 어떤 순서로 하세요? 회사에서 부르시는 이름 그대로요." [납품 · 단계]
4. "배송 기사님 배정이나 도는 순서는 누가 정하세요?" [납품 · 담당]
5. "납품이 끝났다는 건 무엇으로 받으세요? 거래명세서 서명인가요?" [납품 · 끝·증거]
6. "주문한 것이 모자라 일부만 보낼 때는 어떻게 하세요?" [납품 · 안 되는 날]
7. "반품이나 교환은 어떻게 받으세요?" [납품 · 되돌리기]
8. "월말 결제는 무엇으로 맞춰 보세요?" [정산 · 정산·후속] — 이어서: "못 받은 곳은 어떻게 챙기세요?"

**3차 화면·항목 제안**
1. "납품 목록 한 줄에 납품일·거래처·품목 요약·배송 기사·지금 단계를 보이면 될까요?" [3-1]
2. "납품 한 건에는 주문일·거래처·품목과 수량·납품일·기사·명세서 서명 여부·메모를 적으면 될까요?" [3-3]
3. "아침 첫 화면에 오늘 배송할 거래처와 아직 준비가 안 된 주문이 보이면 될까요?" [3-2]
4. "거래처별 월말 정산과 못 받은 돈 확인은 돈 흐름 단계로 미뤄도 될까요?" [3-7]

### 3.3 동네 매장 (소매)

예: 꽃집 · 문구·잡화 · 철물점 · 반찬 가게 · 정육점

- **이 업종의 말**: 한 건 → 예약 주문·배달·발주 · 물건 → 상품 · 들여오기 → 발주(입고) · 단골 → 단골손님
- **관리 단위**: 계산대에서 끝나는 판매는 세지 않는다. 따로 챙기는 일에서 고른다 — 예약 주문 · 배달 · 발주.
- **첫 흐름 후보**: 예약 주문 → 전달 완료 · 발주 → 입고 확인 · **구조 추천**: list — 날짜순으로 하루 일을 훑는다
- **증거 예**: 주문 확인 메시지 · 준비 완료 표시 · 전달(픽업) 체크 · 입고 확인 · **막히는 곳**: 예약 날짜를 놓친다 · 떨어진 물건을 늦게 안다

**1차 세부**
1. "그 자리에서 사 가시는 것 말고 따로 챙기는 주문(예약·배달)이 있나요?" (있으면 1-12는 그 주문 기준으로 묻는다)
2. "물건은 어디서, 얼마나 자주 들여오세요?"

**2차 흐름**
1. "예약 주문은 어떻게 받으세요? 전화·메시지·방문 중에요." [예약 · 시작]
2. "받은 예약은 어디에 적어 두세요?" [예약 · 도구]
3. "예약한 날에는 어떤 순서로 준비하세요?" [예약 · 단계]
4. "손님이 찾아가셨다는 건 무엇으로 남기세요?" [예약 · 끝·증거]
5. "배달은 누가, 언제 나가세요?" [배달 · 담당]
6. "물건 들여오기(발주)는 무엇이 보이면 하세요?" [발주 · 시작]
7. "들어온 물건은 무엇으로 확인하세요?" [발주 · 증거]
8. "예약을 바꾸거나 취소하시면 어떻게 하세요?" [예약 · 되돌리기]

**3차 화면·항목 제안**
1. "예약 주문 목록 한 줄에 찾아갈 날짜·시간·상품·준비 여부를 보이면 될까요?" [3-1]
2. "예약 한 건에는 받은 날·찾아갈 날짜와 시간·상품·요청 사항·받은 방법·손님 칸·준비 완료·전달 체크를 적으면 될까요?" [3-3]
3. "아침 첫 화면에 오늘 준비할 것과 오늘 찾아갈 것이 시간순으로 보이면 될까요?" [3-2]
4. "단골손님 목록은 다음으로 미뤄도 될까요?" [3-7]

### 3.4 대여 (렌탈)

예: 장비 대여 · 행사 용품 · 정수기·생활가전 관리

- **이 업종의 말**: 한 건 → 대여 건(계약) · 물건 → 대여 물품 · 끝 → 반납(회수) · 정기 → 점검(관리 방문)
- **관리 단위**: 대여 건 · 점검. 두 층: 대여 물품(계속 있음) / 대여 건(매번 생김) → 대여 건이 관리 단위, 물품은 고르기 칸(같은 물품이 겹치게 나가지 않는지가 핵심).
- **첫 흐름 후보**: 예약 → 출고 → 반납 확인 · 정기 점검 → 완료 · **구조 추천**: list — 나가는 날·돌아오는 날로 훑는 일이 많다
- **증거 예**: 출고 사진 · 반납 확인 · 점검표 · **막히는 곳**: 반납 날짜가 지났는데 못 챙긴다 · 같은 물건이 두 번 예약된다

**1차 세부**
1. "빌려 드리는 기간이 보통 며칠인가요, 몇 달인가요?" [1-5 대신]
2. "돌려받을 때 상태를 확인하시나요?"
3. "정기적으로 점검하러 나가시나요?"

**2차 흐름**
1. "대여 예약은 어떻게 받으세요?" [대여 · 시작]
2. "그 날짜에 물건이 비어 있는지는 무엇으로 확인하세요?" [대여 · 도구]
3. "내보낼 때 무엇을 확인하고 남기세요?" [대여 · 증거]
4. "배송·설치는 누가 하세요?" [대여 · 담당]
5. "돌려받을 때 무엇을 보고 '반납 끝'이라고 하세요?" [대여 · 끝]
6. "망가지거나 늦게 돌려주시면 어떻게 하세요?" [대여 · 되돌리기·안 되는 날]
7. "정기 점검은 언제, 누가 챙기세요?" [점검 · 시작·담당]

**3차 화면·항목 제안**
1. "대여 목록 한 줄에 물품·나가는 날·돌아올 날·지금 단계를 보이면 될까요?" [3-1]
2. "대여 한 건에는 물품·기간·배송 방법·출고 사진·반납 확인·상태 메모를 적으면 될까요?" [3-3]
3. "아침 첫 화면에 오늘 나갈 것·오늘 돌아올 것·반납이 늦은 것이 보이면 될까요?" [3-2]
4. "물품별 빈 날 달력은 다음으로 미뤄도 될까요?" [3-7]
