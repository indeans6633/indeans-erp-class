# 공유 갤러리 제출 양식

수강생이 **스스로 올리고 싶을 때만** 씁니다. 스킬이 자동으로 수집하거나 어디로 보내지 않습니다. 이 파일은 양식일 뿐이고, 실제 제출은 대표가 직접 합니다(수업에서 안내하는 폴더나 주소에 파일을 올리는 방식).

## 왜 공유하나

다른 수강생이 "그런 방법이 있었구나"를 얻어 가기 위해서입니다. 자랑이 목적이 아니라 **방법 전달**이 목적이라 잘된 것보다 **어디서 막혔고 어떻게 풀었는지**가 더 쓸모 있습니다.

## 올리기 전 확인 (하나라도 아니면 올리지 않습니다)

- [ ] 화면 캡처에 고객·직원 실명, 연락처, 계좌, 주소, 실제 금액이 없다(예시 값으로 바꿨다).
- [ ] 거래처 이름·단가처럼 우리 회사가 밖에 알리면 곤란한 정보가 없다.
- [ ] 다른 사람이 만든 그림·글꼴·문구를 그대로 쓰지 않았다(썼다면 출처를 적었다).
- [ ] 같이 만든 사람이 있으면 그 사람도 공개에 동의했다.
- [ ] 이 내용이 공개되는 것에 내가 동의한다.

## 제출 파일 — `company/gallery-entry.md`

```markdown
# 공유: <한 줄 제목>

- 업종: <제조 / 서비스 / 유통 / 예약 / 기타> (회사 이름은 선택)
- 만든 사람: <이름 또는 별칭>
- 만든 시점: <N회차 / 최종 회>
- 공개 범위: <같은 기수 수강생만 / 인디언즈 강의 자료에 사례로 사용 허용>

## 무엇을 공유하나
<한 문단. 어떤 화면·기능인지, 무엇을 해결했는지>

## 왜 만들었나
<원래 어떻게 일하고 있었는지, 무엇이 불편했는지>

## 어떻게 만들었나
- AI에게 한 말: "<요청 원문 — 그대로>"
- 몇 번 만에 됐나: <횟수>
- 중간에 막힌 것과 푼 방법: <한두 줄>

## 화면
- `screens/01-<이름>.png` — <무엇을 보여 주는 장면>
  (실명·금액·연락처 없음 확인)

## 다른 회사가 쓰려면
<업종이 달라도 통하는 부분 / 우리 회사에만 해당하는 부분 구분>

## 출처 표기
- 이 기능은 <직접 만듦 / 스킬 이름> 을 바탕으로 만들었습니다.
- 참고한 외부 자료: <없음 / 이름·주소>

## 동의 문구
이 글과 화면 캡처를 같은 기수 수강생에게 공개하는 것에 동의합니다.
<인디언즈가 강의 자료·소개 글에 사례로 쓰는 것에도 동의합니다 / 동의하지 않습니다>
공개 뒤에도 내가 원하면 내려 달라고 요청할 수 있음을 확인했습니다.

<이름 또는 별칭> · <YYYY-MM-DD>
```

## 공유하지 않는 것

- 접속 정보(주소·아이디·비밀번호·열쇠 값). 화면 캡처에 주소창이 보이면 가립니다.
- 우리 회사 원가·단가·거래 조건.
- 남의 회사 자료를 옮긴 것.
- 다른 수강생의 화면(본인 동의 없이).

## 내리고 싶을 때

올린 뒤라도 언제든 내릴 수 있습니다. 수업 담당자에게 파일 이름만 알리면 됩니다. 이유를 설명할 필요는 없습니다.
