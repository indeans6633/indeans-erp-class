# 시연에서 말할 문장 예시 (업태별)

대표의 말투로 바꿔 쓰기 위한 **뼈대**입니다. 그대로 읽지 말고 자기 회사 말로 고쳐 씁니다. 회사 이름·고객 이름은 넣지 않습니다.

## 여는 문장 (15초)

첫 문장은 **풀려던 문제와 잰 숫자**다(전후 측정표의 첫 줄). ○는 대표가 직접 잰 값으로만 채운다. 둘째 문장에서 무엇을 바꿨는지 말한다.

| 업종 | 예시 |
|---|---|
| 제조 | "주문이 지금 어디까지 갔는지 묻는 전화가 하루 ○번이었는데, 2주 동안 같은 방법으로 세어 보니 ○번이었습니다. 공장에 넣은 날과 나간 날을 따로 적던 걸 한 화면에 모았습니다." |
| 서비스(출장·설치·수리) | "오늘 누가 어디로 가는지 단톡방에서 다시 묻는 일이 하루 ○번이었는데, 지금은 ○번입니다. 끝났는지도 앱에서 봅니다." |
| 유통·도소매 | "월말에 입고와 출고를 맞추는 데 ○시간 걸렸는데, 이번 달은 ○시간이었습니다. 엑셀 두 개를 하나로 합쳤습니다." |
| 예약업(학원·병의원·미용) | "예약 확인 전화가 하루 ○통이었는데, 2주 재 보니 ○통입니다. 수첩에 적던 예약을 앱에 적고, 오늘 올 사람이 화면에 뜹니다." |
| 숫자가 안 줄었을 때 | "○○을 줄이려고 했는데, 재 보니 그대로였습니다. 이유는 ○○이었고, 그게 다음 30일의 1번입니다." |

## 시연 중 문장 (화면당 1~2줄)

- 목록 화면: "여기가 지금 진행 중인 것 전부입니다. 위에서부터 <기준> 순서입니다."
- 입력 화면: "새로 들어오면 여기서 이 네 가지만 적습니다. 나머지는 자동으로 붙습니다."
- 오늘 할 일 화면: "아침에 이 화면만 봅니다. <오늘 해야 할 것>이 여기 다 있습니다."
- 상태 바뀜: "다 되면 이걸 누릅니다. 그러면 <다음 사람> 화면에 뜹니다."

## 솔직하게 말하는 문장

- "이 화면은 아직 껍데기입니다. 다음 달에 붙일 생각입니다."
- "여기까지는 앱으로 하고, 이 뒤는 아직 손으로 합니다."
- "한 번 잘못 만들어서 되돌렸습니다. 되돌리는 법을 배운 게 더 컸습니다."
- "직원한테 써 보라고 했는데 안 썼습니다. 이유가 <이유>라서 그걸 먼저 고치려고 합니다."

## 만든 과정에서 자주 나오는 배움 (한 줄 정리 예시)

- "한꺼번에 시키면 엉뚱한 게 나오고, 하나씩 시키면 거의 맞습니다."
- "'이렇게 해 줘'보다 '지금 이게 불편하다'를 말하는 게 결과가 낫습니다."
- "고치기 전에 되돌릴 지점을 만들어 두면 겁이 없어집니다."
- "화면을 늘리는 것보다 안 쓰는 화면을 지우는 게 더 좋아졌습니다."

## 마무리 문장 (2분 끝)

- "다음 30일은 <개선 1> 하나만 제대로 하려고 합니다."
- "직원 <N>명까지 같이 쓰는 걸 목표로 잡았습니다."
- "매달 <금액대> 안에서 유지하고, 넘으면 <무엇>을 먼저 멈추기로 했습니다."

## 하지 않는 말

- "AI가 다 해 줬습니다" — 무엇을 결정했는지 대표가 말해야 시연이 됩니다.
- "완성했습니다" — 30일 계획이 있다는 건 완성이 아니라는 뜻입니다. "첫 버전을 만들었습니다"가 맞습니다.
- 다른 회사·다른 수강생 앱과의 비교.
- 실제 매출·단가·고객 이름.
- "확 줄었습니다", "몇 배 빨라졌습니다" — 재지 않은 효과. 직접 잰 숫자만 말합니다.
